# Nhật ký học ETL theo từng buổi

Mỗi bài học sẽ có một file riêng để ghi lại:

- Mục tiêu buổi học
- Câu hỏi / vấn đề cần giải quyết
- Công việc đã làm
- Kết quả
- Vấn đề còn lại
- Bước tiếp theo

## Cấu trúc khuyến nghị

```text
docs/logs/
├── README.md
├── bai-01-template.md
├── bai-02-template.md
├── bai-03-template.md
├── bai-04-template.md
└── ...
```

## Template dùng cho từng bài

Mỗi file nên chứa các phần sau:

1. Tên bài
2. Mục tiêu
3. Bối cảnh dữ liệu / business requirement
4. Phương pháp / kỹ thuật áp dụng
5. Code đã viết
6. Kết quả chạy thử
7. Lỗi gặp phải và cách xử lý
8. Kết luận / ghi chú
9. Plan cho buổi sau

---

Hướng dẫn:
- Không cần ghi quá nhiều nội dung dài dòng
- Ghi theo kiểu “ngày hôm nay làm gì” để dễ review sau này
- Dùng tiếng Việt để đồng bộ với tư duy học tập
