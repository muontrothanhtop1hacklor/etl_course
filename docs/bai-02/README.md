# Bài 02 - Silver và Data Quality

## Mục tiêu
Làm sạch và chuẩn hóa dữ liệu từ Bronze để tạo dataset phù hợp cho phân tích và tầng Gold.

## Phạm vi
- Đọc dữ liệu Bronze
- Chuẩn hóa kiểu dữ liệu và giá trị null
- Xử lý duplicate và bản ghi không hợp lệ
- Tách dữ liệu hợp lệ và không hợp lệ
- Giữ lại dữ liệu gốc để có thể truy vết
